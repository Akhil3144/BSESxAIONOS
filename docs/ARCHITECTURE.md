# Architecture

One FastAPI application invokes a single NegotiationIntelligenceAgent to coordinate the six steps. A native ES-module frontend requests authenticated same-origin APIs. Ingestion accepts bounded CSV/XLSX files, stores original bytes in protected database records and validates canonical source rows. A reviewer/admin freezes an immutable dataset. A case points to one snapshot and preserves its quote. The Decimal engine screens comparators and computes a result under a selected versioned policy. It defaults to deterministic explanations; an explicitly configured structured-plan adapter can select approved prose/evidence without numerical authority. No live call has been verified. Supplier context is sourced from a separate internal performance table. Each calculation is appended as a run; reviews refer to an exact run. Reports retain an exact source/result/review snapshot, archived PDF bytes and SHA256 of exported bytes. Blind evaluation stores separate holdout outcomes and locks predictions before revealing them.

Module boundaries: `security.py` identity/access; `db.py` SQLAlchemy schema and audit; `engine.py` validation, comparability, conversion and pricing; `main.py` API/orchestration; `agents.py` coordinated benchmark/context/validated-narrative assembly; `seed.py` deterministic synthetic data; `reporting.py` ReportLab; `ai.py` guarded narrative contract; `integrations.py` disabled/fixture providers. The first pilot intentionally consolidates modules; splitting ingestion/evidence/review services and replacing JSON payload entities with domain tables remains Phase 1 work.

SQLite was exercised locally with foreign keys enabled. SQLAlchemy and the deployment manifest support PostgreSQL via psycopg, but no PostgreSQL runtime validation has been performed. Alembic has an initial schema revision. Synchronous database work is appropriate to this restricted pilot; no asynchronous workers, enterprise scaling, HA/DR or managed operations are claimed.

No supplier messaging, contract award, procurement write-back, ERP replacement or independent risk agent exists. No documents are sent to an external model. External adapters are disabled and cannot retrieve production data.
