# Public sources and verification

Public sources are versioned in `backend/app/public_sources.json`, independently of synthetic procurement records and frozen pricing snapshots. Review date: 30 October 2026. The current URL is `current_url`; `original_url` and `historical_verifications` preserve the previous URL and complete original verification record. No old result was overwritten or promoted into a new document's provenance.

- GeM remains https://gem.gov.in/ — procurement context only, with no authenticated exact listing or price and no configured GeM API.
- KEI replacement: https://www.scribd.com/document/1070412982/KEI-Cable-List-Price-13th-Mar-2026 — Third-party published price-list copy — authenticity and comparability pending. Direct HTTPS GET returned 200 and its page title was inspected. No exact price row, document authorship or effective date was authenticated. Scribd may require sign-in/subscription or restrict regional access. Original Raj Electricals PDF and HTTP 404 remain in provenance history.
- Technical replacement: https://cdnbbsr.s3waas.gov.in/s303412aef4dcdee4f934f7bf599f89783/uploads/2025/06/202506302010749769.pdf — Government-hosted technical specification — not price evidence. Direct GET returned 200; the 120-page PDF was inspected. The publisher is Uttarakhand Power Corporation Ltd., not NFL. PDF pages 9–11, sections 1.1 and 1.4 and Table 1-3 cover 11 kV, aluminium, XLPE, three-core sizes including 95–400 sq. mm. Original NFL PDF, HTTP 500 and its distinct 185 sq. mm technical evidence remain unchanged in history. Content SHA-256 values identify the retrieved replacement page/PDF without claiming manufacturer authentication.

No verified public price observations exist. No public price import/normalization endpoint is enabled. Synthetic prices were not extracted from these references. Public references never enter the pricing engine or automatically alter saved fair-value ranges or targets. This change does not modify benchmark rules, target calculations or historical data.

Source comparison checks recorded specification fields against each selected synthetic case. The government document includes the seeded 95 sq. mm size; it must not inherit the older NFL 185 sq. mm-only constraint. Missing armour, sheath, voltage class and standards mean the seed remains **Not directly comparable**. Explicit mismatches are identified. Even if all technical fields match, commercial comparability remains unconfirmed; no price comparison is fabricated.

Authenticated users can GET `/api/public-sources/{source_id}/availability` from each card's Check availability action. Open Original Source also checks status in the application while opening the current URL in a new tab. Checks accept only configured source IDs, use an eight-second network timeout, read at most an initial content chunk, do not follow redirects and cache results for five minutes. HTTP errors, restricted/redirected access, unexpected HTML instead of PDF, timeouts and network failures have explicit messages. Availability does not authenticate a document or price. Check results are ephemeral and never overwrite versioned verification history. Cards display the date of the recorded result separately from a new check timestamp.

All four existing roles can inspect the directory and perform availability checks. Case comparison enforces tenant scope and analysis integrity. No holdout outcomes are disclosed. Summary counts reflect the actual database and can exceed the initial 40 records / 5 quotations / 10 holdouts after demo use.

Validation: 142 backend regression tests passed, covering provenance history, replacements, specification mismatches and missing fields, permissions, tenant isolation, immutable calculations, chatbot sources, HTTP errors, network failures, redirect handling and cache behavior. Google Chrome integration passed current source hrefs and new-tab navigation, simulated HTTP 500/check-service failures, benchmarking comparison, Evidence Card and chatbot links with zero JavaScript errors. Replacement URLs were checked independently with direct HTTPS GET. Manager guide PDF rendered and visually reviewed across all nine pages.

Run `.venv/bin/python -m pytest backend/tests -q` and `.venv/bin/python scripts/verify_public_sources.py --base-url http://127.0.0.1:8001` with the local app running and authorized credentials in `.env`. `--base-url` also supports an authorized live deployment. Chrome navigation tests intercept external page contents to keep regression tests independent of external uptime; independent direct link checks and the application availability endpoint provide separate availability evidence.
