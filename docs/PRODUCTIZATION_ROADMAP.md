# Productization roadmap

Phase 0 remaining: original proposal assessed; approve category/schema and input evidence; independently curate real holdouts; approve comparator and normalization rules; approve statistical baseline and thresholds; complete reviewer objection capture; assess 8–12 real historical cases; generate/review 4–5 actual packs; complete M0 go/no-go review.

Phase 1 (proposal weeks 9–11): normalize domain schema, split reusable services, category/version mappings and rule registry, authenticated enterprise access model, frozen interface contracts, richer ingestion preflight and regression tests; M1 review.

Phase 2 (weeks 12–14): 2–3 approved category profiles, evidence-backed adjustments, extended review cockpit, actual licensed source adapters with documented endpoints/entitlements/authentication and mock plus live tests, category-level evaluations; M2 review. Current adapters are disabled/fixture contracts only.

Phase 3 (weeks 15–16): security hardening, observability and defect management, agreed performance/security tests, full UAT, restore/runbook/training, deployment validation and handover; M3 review and external security/release authorization.

All windows are proposal targets, not promises or completed approvals. No SAP write-back, autonomous negotiation, award, blacklisting, general forecasting, enterprise warehouse or unrelated procurement expansion.
