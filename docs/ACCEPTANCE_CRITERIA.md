# Acceptance criteria

Technical synthetic review: start locally, authenticate, initialize/import labeled synthetic source evidence, inspect errors and retained originals, freeze a dataset, create/select a case, calculate source-linked comparables, inspect transformations and provisional band, inspect supplier context and deterministic explanation, download a PDF, record a review transition and run locked historical tests with failures visible. These are exercised by calculation/API tests plus browser QA; see TEST_RESULTS for actual run status.

External acceptance still required: original proposal content comparison completed; choose actual pilot category; approve source schema/authenticity, comparator and normalization rules, sample threshold, band/target/outlier methodology, holdout rubric/pass thresholds and walk-away policy; review real cases and packs; verify confidential-data handling, hosting, roles/retention/security and operational controls; complete UAT/training/handover and obtain M0/M1/M2/M3 decisions. Passing software tests does not grant these approvals.

No criterion accepts autonomous procurement authority. All recommendations remain advisory; acceptance never creates a PO, transmits a supplier offer, updates SAP/SRM or awards a contract.
