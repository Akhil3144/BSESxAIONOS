# Provisional benchmark methodology

The original proposal §5.3 requires a transparent internal-history/comparable method for a homogeneous Phase 0 family. It does not approve specific quantiles, sample thresholds, weights or confidence calibration. The implementation is a candidate baseline requiring SME review; it is not a market price, guarantee or BSES-approved statistical policy.

New runs identify `deterministic-pricing-v2` and persist the fully resolved rule. New empty deployments initialize `demo-quantiles-v2`; existing active policy versions are preserved, enriched with explicit compatible defaults for new fields and linked to the v2 engine version in new results. Archived runs/reports are never rewritten. An old result's original implementation/rule remains authoritative for its reproduction.

Eligibility: complete required cable attributes (voltage_kv, conductor, area_mm2, cores, insulation); exact material/specification/currency/tax/location/delivery and optional freight/price basis; equivalent whole payment days; positive finite prices/quantities; SI m/km conversion; source observation and optional evidence-availability date strictly before quote; optional max_age_days; configurable quantity ratio band. Duplicate IDs/source observations, same source/current event and outcome-bearing records are excluded. Unsupported commercial or market adjustments are refused.

Default policy: minimum five observations, minimum one distinct supplier, quantity ratio 0.5–2x, no age ceiling, Q25/Q75 band and Q50 target, retain outliers and show provisional IQR diagnostic (multiplier 1.5). Supplier counts and single-supplier limitations are explicit. Rule proposal/independent activation exposes quantiles, quantity bounds, age/diversity and IQR thresholds. Retain is the only supported outlier treatment; excluding or winsorizing requires a separately approved implementation.

For sorted normalized prices, quantile position `(n-1)*q` uses linear interpolation. Best=min; median independently calculated. Proposed target is the configured quantile, described accurately in text. Opportunity=`max(0, quote - unrounded target) * quoted quantity`; difference=`(quote - unrounded target)/unrounded target*100`. Local Decimal context uses precision 50 and half-even rounding to 0.01, independent of ambient thread precision. Unrounded values/formula/rounding persist for reproduction. SI conversions are mathematical unit transformations, not inferred volume discounts.

If observation or supplier thresholds fail, return insufficient_evidence without target/opportunity. No calibrated numerical confidence is invented. Qualitative evidence assessment shows source count, diversity, limitations, outlier flags and exclusions. Mixed-currency opportunities are grouped; no converted or summed scalar is shown. BSES must approve category attributes, eligibility/quantity/age bounds, minimums, weighting, quantiles, rounding, outlier treatment, challenge/walk-away decisions and historical acceptance thresholds.
